# CSE6242-Team-103
Workspace for Team 103 Group Project

This repository holds the work Team 103 would like to share. The goal is to make our scripts and code easy to find, reuse, and build on, both for teammates and for anyone else who wants to look at what we've done.

What's Here

The repo is meant to collect any scripts or code from the project, such as:

Data collection and cleaning scripts
Analysis and modeling code
Visualization code
Notebooks and helper utilities
Contributing

Everyone on the team is welcome to add, edit, or remove files as the project evolves. A few light guidelines:

Keep code organized in folders that make sense for the type of work (for example data/, scripts/, notebooks/, viz/).
Add a short comment or docstring at the top of each script explaining what it does and how to run it.
List any dependencies or setup steps (for example in a requirements.txt) so others can reproduce your work.
Avoid committing large data files or credentials. Link to the data source instead.
